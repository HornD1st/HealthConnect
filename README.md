# HealthConnect Healthcare Insights Project

## Project Description
This project focuses on analyzing patient treatment data to identify critical factors influencing treatment success. By leveraging data-driven insights, we aim to improve healthcare outcomes and provide innovative solutions.

## Contents
1. **Analysis Report**  
   - Comprehensive findings and insights are documented in [HealthConnect_Report.pdf](HealthConnect_Report.pdf). The report details demographic distributions, treatment success rates, billing patterns, and actionable recommendations.

2. **Visualizations**  
   - [Health Connect Vizes.pdf](Health%20Connect%20Vizes.pdf) contains detailed visual analyses, showcasing distributions of health conditions by gender, region, and average treatment success rates.

3. **Notebook**  
   - The data analysis process is captured in the Jupyter Notebook, [Health Care Project (Chimaobi Okolo).ipynb](Health%20Care%20Project;%20(Chimaobi%20Okolo).ipynb), including:
     - Data loading and preprocessing.
     - Exploratory data analysis.
     - Implementation of a decision tree model for predictive analysis.

## Key Highlights
- **Dataset**: Covers 4,999 patients with features such as age, gender, diagnoses, treatments, and billing amounts.
- **Predictive Model**: A decision tree with 34% accuracy was developed, offering insights into treatment success probabilities.
- **Recommendations**: Data quality improvements, personalized treatment strategies, and cost optimizations to enhance healthcare outcomes.
